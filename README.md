# Wario Land 3 AP PopTracker

To install, just place the latest release zip in the "packs" folder in your PopTracker installation.

## Current Issues

Autotracking does not automatically change settings. Each time the poptracker is fully reset, the user needs to open the settings popup to reset them manually.
